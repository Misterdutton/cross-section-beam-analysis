# Cross section beam analysis

**[▶ เปิดใช้งานแอปคำนวณคาน คลิกที่นี่](https://misterdutton.github.io/cross-section-beam-analysis/)**

เว็บแอปต้นแบบคำนวณหน้าตัดคานคอนกรีตเสริมเหล็ก ภาษาไทย ใช้บนคอมพิวเตอร์และมือถือได้ พร้อมรูปเหล็กบน–ล่าง คำแนะนำ และโหมดออฟไลน์

## เปิดใช้งานที่หน้างาน

เปิดลิงก์ HTTPS ออนไลน์ครั้งแรกและรอ **พร้อมใช้ออฟไลน์** ก่อนออกหน้างาน ใช้ปุ่ม **ติดตั้งบนหน้าจอหลัก** หรือเพิ่มจากเมนูเบราว์เซอร์ Safari/Chrome จากนั้นเปิดแอปที่ติดตั้งได้แม้ไม่มีเครือข่าย ตราบที่เบราว์เซอร์ยังเก็บข้อมูลเว็บไว้ การเปิดครั้งแรกบนเครื่องใหม่ การล้างข้อมูล และเอกสารภายนอกยังต้องใช้อินเทอร์เน็ต

ปุ่ม **บันทึกในเครื่อง** เก็บค่าที่กรอกในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ส่งค่าโครงสร้างขึ้น GitHub ปุ่ม **โหลดที่บันทึก** นำค่ากลับมาให้ตรวจและคำนวณใหม่ ข้อมูลไม่ซิงก์ข้ามเครื่องโดยอัตโนมัติ

## ขอบเขตวิศวกรรม

กำลังหน้าตัดอ้าง ACI 318-19 ส่วนระยะฝังตรง/ทาบชั้น B รับแรงดึงอ้างข้อกำหนดที่ระบุของ วสท. 011008-21 ใช้เหล็กข้ออ้อยไม่เคลือบ ขนาดเดียว คอนกรีตน้ำหนักปกติและเหล็กชั้นเดียวต่อด้าน รายการที่ต้องใช้ผลวิเคราะห์เพิ่มเติมแสดง **ยังไม่ตรวจ**

เป็นต้นแบบสำหรับตรวจทาน ต้องตรวจสูตรกับมาตรฐานฉบับที่ได้รับอนุญาตและให้วิศวกรตรวจแบบก่อนก่อสร้าง ไม่ถือว่าตรวจครบทั้งมาตรฐาน ไม่ครอบคลุมของอ แผ่นดินไหว รอยต่อและการใช้งานทุกเงื่อนไข การเปลี่ยนขนาดคานต้องวิเคราะห์แรงใหม่

## พัฒนาและตรวจสอบ

ใช้ Node.js 20 หรือใหม่กว่า ไม่มี dependency ที่ต้องติดตั้ง

```sh
node scripts/check.cjs
node scripts/serve.cjs
```

เปิด `http://127.0.0.1:8765` เพื่อทดสอบ โค้ดแอปอยู่ใน `dist/` และชุดทดสอบอยู่ใน `tests/`

## เผยแพร่ GitHub Pages

เตรียม repository ชื่อ `cross-section-beam-analysis` แล้วเลือก Settings → Pages → Source → GitHub Actions จากนั้น workflow `.github/workflows/pages.yml` จะตรวจสอบและเผยแพร่ `dist/` เมื่อ push เข้า `main` URL จริงขึ้นอยู่กับบัญชีเจ้าของและผล deploy ใน GitHub Actions ไม่ต้องเปิดเครื่องพัฒนาค้างไว้

สำหรับ GitHub Free โดยทั่วไปต้องใช้ repository สาธารณะเพื่อเปิด Pages ดูข้อกำหนดปัจจุบันที่ [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) ห้ามนำข้อมูลโครงการส่วนตัว รหัสผ่าน หรือโทเคนใส่ใน repository สาธารณะ

## อัปเดตแอปออฟไลน์

เมื่อแก้ asset ใน `dist/` ต้องเพิ่มเลขรุ่นตรงกันใน `sw.js`, `mobile.js`, meta `sdm-app-version` ใน `index.html` และ `package.json` ระบบเก็บทั้งชุดไฟล์ของแต่ละรุ่นไว้ด้วยกัน ไม่สลับสูตรระหว่างรุ่นขณะคำนวณ ผู้ใช้กดอัปเดตเมื่อพร้อมได้ ข้อมูลฟอร์มจะพักไว้ในเครื่องชั่วคราวและต้องกดคำนวณใหม่หลังอัปเดต

ความพร้อมใช้ออฟไลน์ขึ้นกับการเก็บข้อมูลของเบราว์เซอร์และไม่ใช่การรับประกัน uptime ของผู้ให้บริการ
